# Czech Master v8.2: 3D library button icons

Generated with the built-in image_gen tool. The nine original transparent PNGs are saved in this folder; optimized square WebP versions are embedded in `czTeacher-v8.2.html`.

Shared prompt used separately for each subject:

> Use case: stylized-concept. Asset type: single small 3D button icon for a Czech vocabulary learning app. Subject: [SUBJECT]. Exactly ONE standalone symbol. Premium polished clay and translucent glass hybrid, softly rounded forms, rich saturated colors and clear darker edges, front slightly isometric view, soft neutral studio lighting. Recognizable and readable at 24 pixels. True transparent background. Center the entire subject inside the image with generous 20 percent transparent margin on every side; no cropping. No other objects, no fragments, no text, no letters, no watermark, no contact shadow far from the object, no atlas. Cohesive modern language-app 3D icon design.
